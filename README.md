# HR Analytics — Employee Attrition Dashboard

An end-to-end HR Analytics project analyzing employee attrition patterns 
using Python, SQL, and Tableau.

## 📊 Live Dashboard
[View HR Analytics Dashboard on Tableau Public](https://public.tableau.com/app/profile/anshika.sharma3489/viz/HRAnalyticsAttritionDashboard_17806759285210/HRAnalyticsEmployeeAttritionDashboard)

## 🔍 Key Findings
- **Sales department** has the highest attrition rate (~21%)
- **18-25 age group** has the highest attrition (~35%)
- Employees who left earned **~$2,000/month less** than those who stayed
- Employees doing **overtime** have **3x higher attrition** rate

- Algorithm: Random Forest Classifier
- Accuracy: 84.01%
- Top attrition drivers: Monthly Income, Age, Daily Rate
